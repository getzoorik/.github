# Security policy

## Report a vulnerability

Please report it privately. Do not open a public issue, pull request or discussion.

- **On GitHub:** open the repository's **Security** tab and choose **Report a vulnerability**.
- **By email:** write to [founders@zoorik.com](mailto:founders@zoorik.com).

## What to include

- the repository, and the version or commit you tested;
- what the problem is, and what an attacker could do with it;
- the steps to reproduce it, or a proof of concept;
- a fix or a workaround, if you have one;
- whether and how you would like to be credited.

## What happens next

We reply within 3 working days to confirm we have your report. We keep you posted while we work on a fix, and credit you when it ships unless you ask us not to.

Fixes go into the latest release, so please check the problem still happens there.
